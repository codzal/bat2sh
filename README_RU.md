`bat2sh` переводит сценарии Windows batch (`.bat` / `.cmd`) в сценарии
POSIX `bash`. Это максимально точный блочный транслятор, покрывающий
конструкции, которые используются в большинстве реальных bat-файлов, так
что сгенерированные `.sh`-файлы запускаются на Linux / macOS / WSL почти
или совсем без правок руками.

```
batch (Windows)  ──►  bash (Linux / macOS / WSL)
```

---

> **Статус: бета (v0.3).** Многие команды и граничные случаи ещё
> реализуются — проверяйте скрипты через `--analyze` / `-c` перед
> использованием результата.

## Быстрый старт

```bash
git clone https://github.com/codzal/bat2sh.git
cd bat2sh

# сконвертировать один файл и вывести bash-скрипт в stdout
python3 -m bat2sh examples/basics/01_hello_world.bat

# конвертация на месте: myscript.bat -> myscript.sh
python3 -m bat2sh -i myscript.bat

# сконвертировать папку целиком (рекурсивно) и проверить синтаксис
python3 -m bat2sh -c path/to/batch/files/

# необязательный графический интерфейс
python3 frontend.py
```

Сгенерированным скриптам нужен только `bash`: запускайте их командой
`bash имя.sh`.

## Возможности

* **Структура** — пакет `bat2sh/` (`shell` — раскрытие переменных,
  `parser`, `translator`, карта `commands`, `cli`) и тонкий Tkinter-
  фронтенд `frontend.py`.

* **Переменные** — `set`, `set /a`, `set /p`, `%VAR%`, отложенное `!VAR!`,
  подстроки `%VAR:~0,5%` (включая отрицательные `%~-5` со сдвигом к началу
  строки) и замена `%VAR:find=rep%`, аргументы `%1`…`%9`, `%*`, `%~dp0` и
  другие модификаторы `%~`, специальная переменная `errorlevel`.
* **Управление порядком выполнения** — `if`, `if not`, `if /i`,
  `if exist`, `if defined`, `if errorlevel`, строковые и числовые сравнения
  (`equ`/`neq`/`gtr`/`geq`/`lss`/`leq`), ветки `else`, `for`, `for /l`,
  `for /r`, `for /f` (с `tokens=`, `delims=`, `skip=` и источниками
  «строка/файл»), **вложенные** блоки `for` и `if`, `goto` (в том числе
  выход из циклов) и подпрограммы `call` с собственным стеком аргументов.
* **Перенаправление и операторы** — `>`, `>>`, `<`, конвейеры `|` и
  разделители `&`, `&&`, `||`. Устройство Windows `nul` превращается в
  `/dev/null`. Литеральные сравнения вроде `>=` / `<=` внутри текста
  сохраняются.
* **Частые команды** — `echo`, `rem`/`::`, `@`, `cd`, `md`/`mkdir`,
  `rd`/`rmdir` (включая `/s`), `del`/`erase` (включая `/s`), `copy`,
  `move`, `ren`, `type`, `cls`, `pause`, `exit`, `title`, `color`,
  `setlocal`/`endlocal`, `pushd`/`popd`, `shift`, `start`, `dir`, `find`,
  `findstr`, `path`, `choice`, `cmd /c` и многие стандартные команды
  Windows, отображённые на POSIX-аналоги (`tasklist`→`ps`, `xcopy`→`cp -r`,
  `ping`→`ping`, `ipconfig`→`ip`, `setx`→`export`, `timeout`→`sleep`, …).
* **Преобразование путей** — `C:\dir\file` становится `/mnt/c/dir/file`,
  обратные слэши заменяются на прямые.
* **Аудит и отчёты** — `--analyze` находит обращения к реестру, запуск
  Windows-бинарников (с подсказками wine/аналогов) и управление службами;
  `--report out.md|.html` пишет отчёт миграции с покрытием по файлам.
* **Цель PowerShell (бета)** — `--target=ps1` генерирует PowerShell для
  базовых конструкций.
* **shellcheck** — подсказки автоматически при `-c`, если утилита установлена.
* **Интеграция с редактором** — `--install-vscode-task [DIR]` создаёт задачу
  конвертации одной клавишей для VS Code / VSCodium.
* **Runtime-слой** — `--runtime-layer` добавляет `check_errorlevel()` и
  симлинки `/tmp/bat2sh_drives/<X>`; `--strict-bash` вставляет
  `set -euo pipefail`; `-x` делает .sh исполняемым.
* **Свои правила команд** — в `~/.config/bat2sh/config.toml`:
  `[commands] my_tool = "mytool-linux {args}"`.
* **Надёжный ввод** — файлы UTF-8 (с BOM и без) и UTF-16 декодируются
  автоматически.
* **Диагностика как в cmd.exe** — неизвестные команды печатают
  `'x' is not recognized as an internal or external command…`, отсутствующие
  метки сообщают `The system cannot find the batch label specified - X`
  (`goto` останавливает скрипт, `call` продолжает), а при запуске без
  терминала (например, из Dolphin) ошибки показываются диалоговыми окнами
  вместо stderr.

## Использование из командной строки

```bash
# конвертировать файл (результат в stdout)
python3 -m bat2sh script.bat

# записать рядом с входным как script.sh
python3 -m bat2sh -i script.bat
python3 -m bat2sh script.bat script.sh

# читать из stdin
cat script.bat | python3 -m bat2sh -

# конвертировать из stdin и сразу выполнить (ничего не сохраняется)
cat script.bat | python3 -m bat2sh

# сконвертировать папку с .bat/.cmd разом
python3 -m bat2sh examples/

# только проверить синтаксис результата (файлы не пишутся)
python3 -m bat2sh -c script.bat
python3 -m bat2sh -c examples/
```

| Опция | Описание |
| --- | --- |
| `-i`, `--inplace` | Записать `<input>.sh` рядом с входным файлом |
| `-o`, `--output-dir DIR` | Писать вывод в `DIR` (для папки сохраняет дерево каталогов; для одного файла кладёт `<name>.sh` туда) |
| `-c`, `--check` | Только прогнать `bash -n`; файлы не пишутся |
| `-n`, `--no-debug` | Убрать служебные комментарии/заглушки конвертера; оставить только комментарии исходника |
| `-C`, `--no-clobber` | Не перезаписывать существующие файлы |
| `-q`, `--quiet` | Скрыть информационные сообщения (ошибки показываются) |
| `--encoding ENC` | Принудительная кодировка входа (например, `cp1251`, `latin-1`); по умолчанию — автоопределение |
| `--version` | Показать версию и выйти |
| `-h`, `--help` | Показать справку |

Если на входе **папка**, каждый найденный внутри (рекурсивно) `.bat`/
`.cmd` конвертируется в `.sh`, который кладётся рядом.

## Графический интерфейс

Для любителей «нажал — получилось» есть Tkinter-GUI:

```bash
python3 frontend.py
```

Выбор файла/папки, варианты вывода (рядом с входным, указать файл, папка
вывода или только просмотр), режим *только проверка синтаксиса*, живой
просмотр готового скрипта, копирование в буфер, *Сохранить как…*,
выбор кодировки, переключатели *no-clobber* и *quiet*. Есть меню
(File / Edit / Run / Help) и горячие клавиши (`Ctrl+O`, `Ctrl+S`,
`Ctrl+C`, `F5`). Язык интерфейса переключается в меню **Language / Язык**: английский
встроен, остальные языки — подключаемые файлы `languages/<code>.txt`
(например, `languages/ru.txt`), которые можно править любым редактором.

> ⚠️ Переводы интерфейса, кроме английского, могут быть неполными —
> эталонный язык английский. Вики проекта ведётся только на английском.

Каталог [`examples/`](examples/) содержит разобранные по темам
самодостаточные bat-файлы, демонстрирующие (и проверяющие) покрытие

```
examples/
  basics/         переменные, echo, аргументы, подстроки
  control_flow/   if/else, циклы, goto и подпрограммы
  file_operations/  md/copy/move/ren/del/rd с пробелами и перенаправлениями
```

Команда `examples/generate_examples.sh` конвертирует всё дерево одной
командой:

```bash
bash examples/generate_examples.sh
```

## Как это работает

Конвертер разбирает bat-файл в список инструкций и генерирует один
`bash`-скрипт с **диспетчером по счётчику команд**:

```bash
PC=0
dispatch() {
    case $PC in
        0)  ... ; PC=1 ;;
        1)  ... ; PC=2 ;;
        ...
    esac
}
while [ "$PC" -ge 0 ]; do dispatch; done
```

Это честно моделирует `goto`, включая переходы, покидающие блоки
`for`/`if` (`goto` просто выставляет `PC` и делает `return`), а вызываемые
подпрограммы `call :label` становятся обычными bash-функциями с
сохранением/восстановлением стека аргументов.

## Ограничения

`bat2sh` — транслятор, а не эмулятор. Известные особенности:

* `errorlevel` отражает статус **последней выполненной команды**, как и в
  batch: если между командой и проверкой `if errorlevel` выполнилась,
  например, `echo`, значение сбрасывается (так же ведёт себя настоящий
  `cmd.exe`).
* `start` отбрасывает ключи/заголовок и запускает программу в фоне
  (`nohup … &`) — в POSIX нет понятия консоли/сеанса.
* `color`, `mode`, `chcp` и ещё несколько чисто консольных команд —
  no-op.
* Источник команды в `for /f '…'` исполняется как shell-команда с уже
  раскрытыми переменными; батчевый синтаксис внутри повторно не
  разбирается. `cmd /c other.bat` вызывает сконвертированного соседа
  `other.sh`.
* Вычислимые имена переменных (`!prefix_%%i!`) и динамические метки вызова
  (`call :!name!`) не имеют прямых аналогов в bash и не транслируются.

Патчи и примеры bat-файлов, вскрывающие недостающее поведение,
приветствуются.
