`bat2sh` переводит сценарии Windows batch (`.bat` / `.cmd`) в сценарии
POSIX `bash`. Это максимально точный блочный транслятор, покрывающий
конструкции, которые используются в большинстве реальных bat-файлов, так
что сгенерированные `.sh`-файлы запускаются на Linux / macOS / WSL почти
или совсем без правок руками.

```
batch (Windows)  ──►  bash (Linux / macOS / WSL)
```

---

> **Статус: бета (v0.4).** Многие команды и граничные случаи ещё
> реализуются — проверяйте скрипты через `--analyze` / `-c` перед
> использованием результата.

## Быстрый старт

```bash
git clone https://github.com/codzal/bat2sh.git
cd bat2sh

# сконвертировать один файл и вывести bash-скрипт в stdout
python3 -m bat2sh examples/basics/01_hello_world.bat

# конвертация на месте: myscript.bat -> myscript.sh
python3 -m bat2sh -i myscript.bat

# сконвертировать папку целиком (рекурсивно) и проверить синтаксис
python3 -m bat2sh -c path/to/batch/files/

# необязательный графический интерфейс
python3 frontend.py
```

Сгенерированным скриптам нужен только `bash`: запускайте их командой
`bash имя.sh`.

## Возможности (5 китов)

1. **Точное ядро трансляции** — переменные (отложенное раскрытие, подстроки,
   замена без учёта регистра), весь поток управления включая `for /r` и
   «честный» `for /f`, подпрограммы как bash-функции, диагностика в стиле
   cmd.exe и настоящие коды возврата.
2. **Сначала аудит — потом доверие** — `--analyze` находит обращения к
   реестру, Windows-бинарники (подсказки wine/аналогов) и управление
   службами; `--report` пишет отчёт миграции (HTML/Markdown) с покрытием
   по каждому файлу.
3. **Безопасный запуск** — `-r` выполнить сразу, `--diff` просмотр бок о бок,
   `-c` с автоматическими подсказками shellcheck, `--strict-bash`,
   `--runtime-layer`, опциональный `-x`, свои правила команд через TOML-конфиг.
4. **Две цели, любые пути** — по умолчанию bash, бета-PowerShell через
   `--target=ps1`; диски как WSL, Wine или корень (`--path-style`);
   Windows-переменные окружения отображаются на XDG.
5. **Удобные инструменты** — Tkinter GUI (две панели с синхронным скроллом и
   подсветкой, пресеты платформ, русский интерфейс), установка задачи для
   VS Code, snapshot-тесты и CI.

## Использование из командной строки

```bash
# конвертировать файл (результат в stdout)
python3 -m bat2sh script.bat

# записать рядом с входным как script.sh
python3 -m bat2sh -i script.bat
python3 -m bat2sh script.bat script.sh

# читать из stdin
cat script.bat | python3 -m bat2sh -

# конвертировать из stdin и сразу выполнить (ничего не сохраняется)
cat script.bat | python3 -m bat2sh

# сконвертировать папку с .bat/.cmd разом
python3 -m bat2sh examples/

# только проверить синтаксис результата (файлы не пишутся)
python3 -m bat2sh -c script.bat
python3 -m bat2sh -c examples/
```

| Опция | Описание |
| --- | --- |
| `-i`, `--inplace` | Записать `<input>.sh` рядом с входным файлом |
| `-o`, `--output-dir DIR` | Писать вывод в `DIR` (для папки сохраняет дерево каталогов; для одного файла кладёт `<name>.sh` туда) |
| `-c`, `--check` | Только прогнать `bash -n`; файлы не пишутся |
| `-C`, `--no-clobber` | Не перезаписывать существующие файлы |
| `-r`, `--run` | Конвертировать и сразу выполнить (ничего не записывается) |
| `--path-style {wsl,wine,root}` | Стиль отображения дисков |
| `--shebang STR` | Шебанг генерируемого скрипта |
| `-x`, `--executable` | chmod 0700 записанным .sh (только владелец) |
| `--diff` | Показать batch и bash бок о бок |
| `--strict-bash` | Вставить `set -euo pipefail` |
| `-d`, `--debug` | Оставить отладочные комментарии конвертера (по умолчанию вывод чистый) |
| `--analyze` / `--report FILE` | Аудит совместимости / отчёт миграции |
| `--runtime-layer` | Хелперы errorlevel + симлинки дисков |
| `--target {bash,ps1}` | Язык результата (ps1 — бета) |
| `-q`, `--quiet` | Скрыть информационные сообщения (ошибки показываются) |
| `--encoding ENC` | Принудительная кодировка входа (например, `cp1251`, `latin-1`); по умолчанию — автоопределение |
| `--version` | Показать версию и выйти |
| `-h`, `--help` | Показать справку |

Если на входе **папка**, каждый найденный внутри (рекурсивно) `.bat`/
`.cmd` конвертируется в `.sh`, который кладётся рядом.

## Графический интерфейс

Для любителей «нажал — получилось» есть Tkinter-GUI:

```bash
python3 frontend.py
```

Выбор файла/папки (drag & drop при установленном `tkinterdnd2`), варианты
вывода (рядом с входным, указать файл, папка вывода или только просмотр),
режим *только проверка синтаксиса*, язык целевого скрипта (bash / PowerShell)
и пресеты путей, кнопка «Запустить», исполняющая конвертацию в памяти без
записи файла (Ctrl+R), аудит, слой совместимости и свой шебанг.
Неочевидные переключатели объясняют себя
подсказкой при наведении. Живой двухпанельный просмотр с синхронной
прокруткой, копирование в буфер, *Сохранить как…* и выбор кодировки —
на месте. Есть меню (File / Edit / Run / Help) и горячие клавиши
(`Ctrl+O`, `Ctrl+S`, `Ctrl+C`, `F5`). Язык интерфейса переключается в меню
**Language / Язык**: английский встроен, остальные языки — подключаемые
файлы `languages/<code>.txt` (например, `languages/ru.txt`), которые можно
править любым редактором.

> ⚠️ Переводы интерфейса, кроме английского, могут быть неполными —
> эталонный язык английский. Вики проекта ведётся только на английском.

## Примеры

Каталог [`examples/`](examples/) содержит разобранные по темам
самодостаточные bat-файлы, демонстрирующие (и проверяющие) покрытие
конвертера:

```
examples/
  basics/           переменные, echo, аргументы, подстроки
  control_flow/     if/else, циклы, goto и подпрограммы
  file_operations/  md/copy/move/ren/del/rd с пробелами и перенаправлениями
  advanced/         сборочные скрипты, взаимодействие с пользователем,
                    преобразование путей Windows, парсер INI
  complextasks/     40 стресс-примеров: ротация логов, отчёты из CSV,
                    рекурсия, автоматы состояний, retry-циклы и др.
  */ps/             рукописные PowerShell-аналоги каждой категории
```

Каждый пример в CI прогоняется дважды: конвертация обязана пройти `bash -n`,
а вывод `--target=ps1` — парситься под pwsh.

Команда `examples/generate_examples.sh` конвертирует всё дерево одной
командой:

```bash
bash examples/generate_examples.sh
```

Регрессионные golden-тесты: `bash tests/snapshot.sh` — сравнивают конвертацию каждого примера с эталоном из `tests/expected/`.

## Как это работает

Конвертер разбирает bat-файл в список инструкций и генерирует один
`bash`-скрипт с **диспетчером по счётчику команд**:

```bash
PC=0
dispatch() {
    case $PC in
        0)  ... ; PC=1 ;;
        1)  ... ; PC=2 ;;
        ...
    esac
}
while [ "$PC" -ge 0 ]; do dispatch; done
```

Это честно моделирует `goto`, включая переходы, покидающие блоки
`for`/`if` (`goto` просто выставляет `PC` и делает `return`), а вызываемые
подпрограммы `call :label` становятся обычными bash-функциями с
сохранением/восстановлением стека аргументов.

## Ограничения

bat2sh — транслятор, а не эмулятор. Известные особенности:

* `errorlevel` отражает статус **последней выполненной команды**, как в cmd.exe.
* `start` отбрасывает ключи/заголовок и запускает процесс в фоне (`nohup … &`);
  консольных сессий в POSIX нет.
* `color` задаёт только ANSI-цвет текста; `mode`, `chcp` и несколько чисто
  консольных команд — no-op.
* Источник команды `for /f '…'` исполняется как shell-команда, батчевый
  синтаксис внутри повторно не разбирается.
* Вычислимые имена переменных (`!prefix_%%i!`) транслируются в
  `Set-Variable` / bash-косвенные ссылки, но экзотическая вложенность может
  упасть в комментарий-предупреждение.
* `--target=ps1` даёт парс-чистый PowerShell 7 для всех встроенных примеров,
  но остаётся бета: покрытие команд меньше, чем у bash-таргета, семантика —
  best effort.
* Переводы GUI кроме английского могут быть неполными.

Патчи и примеры bat-файлов, вскрывающие недостающее поведение,
приветствуются.
