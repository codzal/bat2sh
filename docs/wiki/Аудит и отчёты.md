# Аудит и отчёты

```bash
python3 -m bat2sh --analyze путь[.bat|папка]
python3 -m bat2sh --analyze examples/ --report report.html
```

## Что детектируется
| id | триггер | совет |
|---|---|---|
| registry | `reg add/query/...` | проверьте логику; при запуске через bat2sh используется JSON-эмуляция |
| regfile | упоминание `.reg` | требуется ручная проверка |
| binary | запуск `*.exe/*.msi/*.com` | обернуть в `wine prog` или заменить аналог; для notepad/calc/mspaint/taskmgr/explorer/msiexec даётся конкретная подсказка |
| service | `net start/stop`, `sc config/start/stop/query`, `vssadmin` | перевести на systemctl/service |
| wmi | `wmic` | прямого аналога нет |

## Отчёт
`--report out.md` (или `.html`) собирает по всем обработанным файлам:
число инструкций, число fallback-строк, процент покрытия и список мест
ручного внимания (`файл:строка`). Покрытие = `(stmts-fallback)/stmts`,
fallback считается для строк, ушедших в passthrough либо не имеющих маппинга.
