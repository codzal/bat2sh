# Быстрый старт

| Задача | Команда |
|---|---|
| Посмотреть bash-результат | `python3 -m bat2sh script.bat` |
| Сконвертировать рядом `.sh` | `python3 -m bat2sh -i script.bat` |
| Указать имя вывода | `python3 -m bat2sh script.bat out.sh` |
| Из папки в файл | `python3 -m bat2sh script.bat -o out.sh` |
| Вся папка рекурсивно | `python3 -m bat2sh examples/` |
| Только проверить синтаксис | `python3 -m bat2sh -c script.bat` |
| Конвертировать и **выполнить** | `python3 -m bat2sh -r script.bat` |
| Через пайп (выполнить) | `cat x.bat \| python3 -m bat2sh` |
| Через пайп (напечатать) | `cat x.bat \| python3 -m bat2sh -` |
| Содержимое аргументом | `python3 -m bat2sh "$(cat x.bat)"` |

Сгенерированный скрипт запускается обычным `bash name.sh`.
Подробности каждого флага — в [[Справочник CLI]].
