# Графический интерфейс

Запуск: `python3 frontend.py`

* Выбор файла/папки, режимы вывода (рядом с входным / указать файл /
  папка вывода / только просмотр).
* Живой просмотр: две панели **batch \| bash** с синхронным скроллом и
  подсветкой ключевых слов/комментариев.
* Пресеты Target: **Pure Bash** / **WSL** (/mnt/c) / **Wine-friendly**
  (~/.wine/drive_c).
* Кнопки Convert/Copy/Save As, прогресс на папках, статус-бар `[beta]`.
* Меню **Language / Язык**: английский встроен, русский — `languages/ru.txt`;
  новые языки = новый txt-файл ([[Языковые пакеты GUI]]).

Ошибки при фоновом запуске (без терминала) показываются диалогами:
tkinter → kdialog → zenity → stderr.
