# Поддерживаемые конструкции

## Переменные
`set`, `set /a` (с защитой от octal: `val=08+2` работает),
`set /p`, `%VAR%`, отложенное `!VAR!`,
`%VAR:~N,M%` (в т.ч. отрицательные N),
замена `%VAR:f=r%` — **регистронезависимая** (как в cmd),
аргументы `%1..%9 %* %~1 %~dp0 %~nx…`, `%ERRORLEVEL%`.
Windows-env → POSIX: `%TEMP%/%TMP%→${TMPDIR:-/tmp}`, `%USERPROFILE%→$HOME`,
`%APPDATA%→${XDG_CONFIG_HOME:-$HOME/.config}`,
`%LOCALAPPDATA%→${XDG_DATA_HOME:-$HOME/.local/share}`,
`%PROGRAMFILES%→/opt`, `%SYSTEMROOT%/%WINDIR%→/etc`, `%COMPUTERNAME%`.

Имена с точками (`config.server.host`) транслируются в `config_server_host`;
динамическая запись `set "a.!sec!.!k!=!v!"` → `printf -v`.

## Управление потоком
`if/not/i/exist/defined/errorlevel`, сравнения `equ neq lss leq gtr geq`
(строковые equ/neq → `[[ ]]`), `else`,
`for`, `for /l`, `for /r [путь]`, `for /f` (`usebackq`, `delims=`=«не резать»,
`skip=`, `tokens=N,N-M,a,N*,*`),
вложенные блоки, цепочки `if A if B (...) else (...)`,
`goto` (включая выход из циклов), `call :label args` — подпрограммы становятся
настоящими bash-функциями, поэтому работают внутри циклов;
`exit /b N` передаёт код возврата.

## Перенаправление
`> >> <`, `\|`, `&&`, `||`, `&`; `nul`→`/dev/null`; литеральные `>= <=` в тексте
не путаются с редиректом.

## Команды (выборка)
echo/rem/::/@, cd, md/mkdir, rd/rmdir (`/s /q`; без `/s` → `rmdir`), del
(`/s /f /q`, несколько масок), copy/move/ren, type, cls, pause
(точно как cmd: `Press any key to continue . . . `), title, color (ANSI),
setlocal/endlocal (no-op), pushd/popd (с переводом пути), shift, start
(флаги, заголовок, URL → xdg-open, `/wait` синхронно), dir, find/findstr,
path, choice (`/t /d /c`, таймаут, rc=255), `cmd /c other.bat`→запуск
сконвертированного соседа.

### Сеть и службы
`ipconfig[/all]`→`ip[-br] addr`, `netstat -ano`→`ss -tulpn`,
`route print`→`ip route`, `nslookup`→`dig +short`,
`netsh wlan show profiles`→`nmcli connection show`,
`sc query/start/stop X`→`systemctl status/start/stop X`,
`sc config X start= auto|demand`→`systemctl enable/disable X`,
`net start/stop`→`systemctl`.

### Системные эмуляции
`attrib ±h/r/x/s` → dot-rename/chmod; `icacls/cacls` → chmod;
`assoc`/`ftype` → xdg-mime; `subst X: path` → симлинк
`~/.local/share/bat2sh/drives/x`; `where` → `which`;
`reg add/query/delete` → JSON-реестр `${BAT2SH_REG:-$HOME/.config/bat2sh/registry.json}`,
при этом ветка `HKLM\...\CurrentVersion` отвечает значениями из `/etc/os-release`
(`ProductName`, `ComSpec=/bin/bash`, `SystemRoot=/`).

## Диагностика как в cmd.exe
Неизвестная команда → `'x' is not recognized as an internal or external command,`
`operable program or batch file.` (errorlevel 9009, выполнение продолжается).
Нет метки у `goto` → сообщение и остановка; у `call` → сообщение и продолжение
(errorlevel 1). Неконвертируемый вход → `The syntax of the command is incorrect.`
и rc=1 вместо падения транслятора.
