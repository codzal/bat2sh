# Установка

## Требования
* Python 3.6+ (для `--target=ps1` и TOML-конфига желателен 3.11+)
* `bash` — для запуска сгенерированных скриптов и проверки `-c`
* `tkinter` — только для GUI (`frontend.py`)
* опционально: `shellcheck`, `kdialog`/`zenity`, `pwsh`

## Из исходников
```bash
git clone https://github.com/codzal/bat2sh.git
cd bat2sh
python3 -m bat2sh -v          # bat2sh 0.3
```

Установка пакетом не требуется: CLI запускается модулем из каталога репозитория.
Для вызова из любого места добавьте алиас:
```bash
alias bat2sh='PYTHONPATH=/путь/к/bat2sh python3 -m bat2sh'
```

## Проверка работоспособности
```bash
python3 -m bat2sh -c examples/     # синтаксис всех примеров
bash tests/snapshot.sh             # snapshot-тесты
```
